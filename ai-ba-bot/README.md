# AI Business Analyst Bot для Битрикс24

ИИ Бизнес-аналитик, интегрированный с Битрикс24 через selfhosted n8n.
Автоматически анализирует задачи, задаёт уточняющие вопросы и обогащает описания.

## Основные функции

1. **Анализ входящих задач** - мониторинг новых задач в Битрикс24
2. **Оценка полноты информации** - ИИ проверяет достаточность данных для выполнения
3. **Уточняющие вопросы** - автоматическая отправка вопросов постановщику
4. **Обновление описания** - обогащение задачи после получения ответов
5. **Уведомления** - информирование исполнителя и заказчика
6. **Авто-тегирование** - классификация задач по категориям

## Быстрый старт

1. Установите selfhosted n8n
2. Настройте подключение к Битрикс24 (OAuth или Webhook)
3. Импортируйте workflow из `workflows/ai-ba-main.json`
4. Настройте ИИ провайдера (OpenAI/Anthropic/локальный LLM)
5. Активируйте workflow

## Требования

- n8n (selfhosted) >= 1.0
- Битрикс24 с правами на работу с задачами
- API ключ для LLM (OpenAI, Anthropic или совместимый)
