# Кейс работы ИИ Бизнес-аналитика

## Сценарий: Обработка задачи на разработку нового функционала

### Исходная ситуация

**Постановщик:** Иванов Пётр (Руководитель отдела продаж)
**Исполнитель:** Сидоров Алексей (Разработчик)

Пётр создаёт задачу в Битрикс24:

```
Заголовок: Добавить отчёт по продажам
Описание: Нужен новый отчёт для менеджеров
Приоритет: Высокий
Дедлайн: через 2 недели
```

---

## Этап 1: Получение задачи (Триггер)

### Что происходит в n8n:

1. **Webhook/Polling** получает событие о новой задаче
2. Данные задачи передаются в workflow
3. Запускается цепочка обработки

### Данные из Битрикс24 API:
```json
{
  "id": "12345",
  "title": "Добавить отчёт по продажам",
  "description": "Нужен новый отчёт для менеджеров",
  "priority": "2",
  "createdBy": "user_101",
  "responsible": "user_205",
  "deadline": "2024-02-01T18:00:00+03:00",
  "status": "2",
  "tags": []
}
```

---

## Этап 2: Анализ задачи (ИИ)

### Промпт для анализа:

ИИ получает задачу и оценивает её по критериям:

| Критерий | Статус | Комментарий |
|----------|--------|-------------|
| Цель задачи | Частично | "Новый отчёт" - слишком общо |
| Ожидаемый результат | Отсутствует | Не указано, как должен выглядеть |
| Целевая аудитория | Частично | "Менеджеры" - какие именно? |
| Данные для отчёта | Отсутствует | Какие метрики включать? |
| Период данных | Отсутствует | За какой период? |
| Формат вывода | Отсутствует | Excel, PDF, на сайте? |
| Критерии приёмки | Отсутствует | Как понять, что готово? |

### Решение ИИ:
**Информации НЕДОСТАТОЧНО** - необходимы уточнения

---

## Этап 3: Генерация вопросов

ИИ формирует список уточняющих вопросов:

```markdown
Здравствуйте, Пётр!

Я - ИИ Бизнес-аналитик. Для качественной постановки задачи
"Добавить отчёт по продажам" мне нужны уточнения:

1. **Цель отчёта:** Для каких бизнес-решений будет использоваться?
   (контроль KPI, прогнозирование, мотивация менеджеров?)

2. **Какие данные включить:**
   - Объём продаж (в рублях, штуках)?
   - По каким менеджерам/отделам?
   - Воронка продаж (лиды → сделки)?
   - Сравнение с планом?

3. **Период:** За какой период нужны данные?
   (день, неделя, месяц, произвольный?)

4. **Формат:** Как удобнее получать отчёт?
   - Таблица в Битрикс24
   - Выгрузка в Excel
   - Графики/дашборд
   - Email рассылка

5. **Доступ:** Кто кроме менеджеров должен видеть отчёт?

6. **Регулярность:** Отчёт нужен разово или на постоянной основе?

Пожалуйста, ответьте на эти вопросы, чтобы исполнитель
мог качественно выполнить задачу.

---
ИИ Бизнес-аналитик
```

---

## Этап 4: Отправка вопросов в Битрикс24

### Действия бота:

1. **Добавляет комментарий** к задаче с вопросами
2. **Меняет статус** задачи на "Ожидает уточнения" (опционально)
3. **Добавляет тег:** `#требует_уточнения`
4. **Отправляет уведомление** постановщику

### API вызов (добавление комментария):
```
POST /rest/task.commentitem.add
{
  "TASKID": 12345,
  "FIELDS": {
    "POST_MESSAGE": "[текст вопросов]",
    "AUTHOR_ID": "bot_user_id"
  }
}
```

---

## Этап 5: Получение ответов

Пётр отвечает в комментариях:

```markdown
1. Цель - контроль выполнения плана продаж за месяц
2. Нужны: объём в рублях, количество сделок, % выполнения плана
   по каждому менеджеру отдела розничных продаж
3. Период - за текущий месяц и сравнение с прошлым
4. Формат - таблица в Битрикс + выгрузка в Excel
5. Доступ - руководители отделов и директор
6. Нужен еженедельно по понедельникам
```

### Как бот узнаёт об ответе:

1. **Webhook на комментарии** - Битрикс24 отправляет событие
2. **Проверка автора** - если это постановщик → обработка
3. **Связывание контекста** - бот помнит, что ждал ответ по задаче #12345

---

## Этап 6: Обновление описания задачи

ИИ формирует обогащённое описание:

```markdown
## Отчёт по выполнению плана продаж

### Цель
Еженедельный контроль выполнения плана продаж отделом розничных продаж.

### Требования к отчёту

**Данные:**
- Объём продаж в рублях
- Количество закрытых сделок
- Процент выполнения месячного плана
- Детализация по каждому менеджеру

**Период:**
- Текущий месяц (нарастающим итогом)
- Сравнение с аналогичным периодом прошлого месяца

**Формат вывода:**
- Таблица в разделе "Отчёты" Битрикс24
- Возможность выгрузки в Excel

**Доступ:**
- Менеджеры отдела розничных продаж (свои данные)
- Руководители отделов (все данные отдела)
- Директор (полный доступ)

### Регулярность
Автоматическая генерация каждый понедельник в 09:00

### Критерии приёмки
- [ ] Отчёт показывает актуальные данные из CRM
- [ ] Есть фильтрация по менеджерам
- [ ] Работает выгрузка в Excel
- [ ] Настроена автоматическая рассылка

---
*Описание сформировано ИИ Бизнес-аналитиком на основе
уточнений от постановщика*
```

### API вызов (обновление задачи):
```
POST /rest/tasks.task.update
{
  "taskId": 12345,
  "fields": {
    "DESCRIPTION": "[обогащённое описание]"
  }
}
```

---

## Этап 7: Проставление тегов

ИИ анализирует задачу и определяет категории:

| Тег | Причина |
|-----|---------|
| `#отчётность` | Задача связана с созданием отчёта |
| `#продажи` | Относится к отделу продаж |
| `#автоматизация` | Требуется регулярная генерация |
| `#high_priority` | Высокий приоритет от постановщика |
| `#crm_интеграция` | Нужны данные из CRM |

### API вызов (добавление тегов):
```
POST /rest/tasks.task.update
{
  "taskId": 12345,
  "fields": {
    "TAGS": ["отчётность", "продажи", "автоматизация", "high_priority", "crm_интеграция"]
  }
}
```

**Ключевые моменты:**

## Метрики эффективности

После внедрения ИИ Бизнес-аналитика можно отслеживать:

| Метрика | До | После (ожидание) |
|---------|-----|------------------|
| Среднее кол-во слов в описании | 10-15 | 150-300 |
| % задач с тегами | 20% | 95% |
| Время на уточнение требований | 2-3 дня | 4-6 часов |
| Переоткрытие задач из-за недопонимания | 30% | 5% |
