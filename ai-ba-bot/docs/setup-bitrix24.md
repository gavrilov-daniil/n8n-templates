# Подключение Битрикс24 к ИИ Бизнес-аналитику

Пошаговая инструкция по настройке интеграции.

---

## Шаг 1: Подготовка n8n

### 1.1 Установка n8n (если ещё не установлен)

**Docker (рекомендуется):**
```bash
docker run -d \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  -e N8N_SECURE_COOKIE=false \
  n8nio/n8n
```

**npm:**
```bash
npm install -g n8n
n8n start
```

### 1.2 Открыть n8n

Перейдите в браузере: `http://localhost:5678`

При первом запуске создайте учётную запись администратора.

---

## Шаг 2: Настройка Битрикс24

### 2.1 Создание входящего вебхука

Входящий вебхук позволяет n8n вызывать API Битрикс24.

1. Откройте Битрикс24
2. Перейдите: **Приложения** → **Разработчикам** → **Другое** → **Входящий вебхук**
3. Нажмите **Добавить вебхук**
4. Выберите права доступа:

| Право | Описание |
|-------|----------|
| ☑️ `task` | Задачи (чтение и запись) |
| ☑️ `user` | Пользователи (чтение) |
| ☑️ `im` | Сообщения и уведомления |

5. Нажмите **Сохранить**
6. **Скопируйте URL вебхука**, он выглядит так:
```
https://ваш-домен.bitrix24.ru/rest/1/xxxxxxxxxxxxxxxxxx/
```

⚠️ **Важно:** Сохраните этот URL, он понадобится для настройки n8n.

### 2.2 Создание исходящего вебхука (события → n8n)

Исходящий вебхук отправляет события из Битрикс24 в n8n.

1. Перейдите: **Приложения** → **Разработчикам** → **Другое** → **Исходящий вебхук**
2. Нажмите **Добавить вебхук**
3. Заполните поля:

| Поле | Значение |
|------|----------|
| **URL обработчика** | `https://ваш-n8n.com/webhook/bitrix-tasks` |
| **Тип события** | `ONTASKADD` (Создание задачи) |

4. Нажмите **Сохранить**
5. Повторите для события `ONTASKCOMMENTADD` (новый комментарий):

| Поле | Значение |
|------|----------|
| **URL обработчика** | `https://ваш-n8n.com/webhook/bitrix-comments` |
| **Тип события** | `ONTASKCOMMENTADD` |

### 2.3 Получение ID пользователя бота

Если вы создаёте отдельного пользователя для бота:

1. Перейдите: **Настройки** → **Сотрудники** → **Добавить**
2. Создайте пользователя "ИИ Бизнес-аналитик"
3. Запомните его ID (видно в URL профиля: `/company/personal/user/123/`)

Или используйте ID существующего пользователя.

## Шаг 3: Настройка OpenAI API

### 3.1 Получение API ключа

1. Перейдите на [platform.openai.com](https://platform.openai.com)
2. Войдите или зарегистрируйтесь
3. Перейдите: **API Keys** → **Create new secret key**
4. Скопируйте ключ (начинается с `sk-...`)

⚠️ **Важно:** Ключ показывается только один раз!

### 3.2 Проверка баланса

Убедитесь, что на аккаунте OpenAI есть средства:
- **Billing** → **Add payment method**
- Рекомендуемый минимум: $10

---

## Шаг 4: Импорт workflow в n8n

### 4.1 Импорт файла

1. Откройте n8n: `http://localhost:5678`
2. Нажмите **Add workflow** (или `Ctrl+N`)
3. Нажмите **⋮** (три точки) → **Import from File**
4. Выберите файл: `ai-ba-bot/workflows/ai-ba-main.json`
5. Workflow появится на холсте

### 4.2 Настройка переменных окружения

В n8n создайте переменные:

1. Перейдите: **Settings** → **Variables**
2. Добавьте переменные:

| Переменная | Значение | Пример |
|------------|----------|--------|
| `BITRIX24_WEBHOOK_URL` | URL входящего вебхука | `https://xxx.bitrix24.ru/rest/1/abc123/` |
| `BOT_USER_ID` | ID пользователя бота | `123` |

### 4.3 Настройка Credentials

#### OpenAI:
1. Перейдите: **Settings** → **Credentials** → **Add Credential**
2. Выберите **OpenAI API**
3. Заполните:
   - **Credential Name:** `OpenAI`
   - **API Key:** ваш ключ `sk-...`
4. Нажмите **Save**

#### Привязка к нодам:
1. Откройте workflow
2. Для каждой ноды `ИИ: ...`:
   - Дважды кликните на ноду
   - В поле **Credential** выберите `OpenAI`
   - Нажмите **Save**

## Шаг 5: Настройка URL вебхуков

### 5.1 Получение URL из n8n

1. Откройте workflow
2. Кликните на ноду **"Вебхук: Новая задача"**
3. Скопируйте **Webhook URL** (справа в панели)
   - Production: `https://ваш-n8n.com/webhook/bitrix-tasks`
   - Test: `https://ваш-n8n.com/webhook-test/bitrix-tasks`

4. Повторите для ноды **"Вебхук: Новый комментарий"**
   - URL: `https://ваш-n8n.com/webhook/bitrix-comments`

### 5.2 Обновление URL в Битрикс24

Вернитесь в Битрикс24 и обновите URL в исходящих вебхуках (Шаг 2.2).

---

## Шаг 6: Активация и тест

### 6.1 Активация workflow

1. В n8n откройте workflow
2. Переключите тумблер **Active** в правом верхнем углу
3. Статус должен стать зелёным

### 6.2 Тестирование

1. В Битрикс24 создайте тестовую задачу:
   ```
   Заголовок: Тестовая задача для бота
   Описание: Нужно что-то сделать
   Исполнитель: [выберите себя или бота]
   ```

2. Подождите 5-10 секунд

3. Проверьте в n8n:
   - **Executions** → должен появиться новый запуск
   - Статус: зелёный ✓ (успех) или красный ✗ (ошибка)

4. Проверьте в Битрикс24:
   - В задаче должен появиться комментарий с вопросами
   - Должен быть установлен тег `ba_pending`

## Шаг 7: Продакшен настройки

### 7.1 HTTPS для n8n

Битрикс24 требует HTTPS для вебхуков. Варианты:

**A) Reverse proxy (Nginx):**
```nginx
server {
    listen 443 ssl;
    server_name n8n.ваш-домен.ru;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:5678;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

**B) Cloudflare Tunnel:**
```bash
cloudflared tunnel --url http://localhost:5678
```

**C) ngrok (для тестов):**
```bash
ngrok http 5678
```

### 7.2 Переменные окружения для Docker

```yaml
# docker-compose.yml
version: '3'
services:
  n8n:
    image: n8nio/n8n
    ports:
      - "5678:5678"
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=сильный_пароль
      - WEBHOOK_URL=https://n8n.ваш-домен.ru/
      - BITRIX24_WEBHOOK_URL=https://xxx.bitrix24.ru/rest/1/abc123/
      - BOT_USER_ID=123
    volumes:
      - n8n_data:/home/node/.n8n
```

## Возможные ошибки

### "401 Unauthorized" от Битрикс24
- Проверьте правильность URL вебхука
- Убедитесь, что вебхук не истёк
- Проверьте права доступа вебхука

### "Connection refused" в n8n
- Проверьте, что n8n запущен
- Проверьте URL в исходящем вебхуке Битрикс24
- Убедитесь, что n8n доступен извне (HTTPS)

### "Invalid API Key" от OpenAI
- Проверьте правильность ключа
- Убедитесь, что ключ активен
- Проверьте баланс аккаунта OpenAI

### Вебхук не срабатывает
- Убедитесь, что workflow активирован
- Проверьте URL в настройках Битрикс24
- Посмотрите логи в n8n (Executions)
